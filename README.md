# js-practice-bmi-calc

JavaScriptの学習の一環としてコツコツ作成している、BMI（体格指数）を算出するシミュレーションアプリです。

## 概要
身長と体重を入力することで、自身のBMI値を計算・可視化するためのシンプルなツールです。

## 学習のポイント・こだわり
- **1日1行からの丁寧な積み上げ**: コードの意味や英単語の構造を一つひとつ理解しながら、手打ちで実装を進めています。
- **論理構造の維持**: 前回に引き続き、プログラムを「入力（Input）」「処理（Processing）」「出力（Output）」のブロックに整理して組み立てています。
- **単位の変換と計算**: 身長（cm）をメートル（m）に変換するロジックや、割り算を伴う計算処理を実践的に学んでいます。

## 使用技術
- HTML / CSS
- JavaScript
